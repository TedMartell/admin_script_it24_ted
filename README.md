# Admin Tool (Python)
Project Description
This project is a Python-based admin tool that simulates common IT administration tasks.
The script allows you to:

### Create users (simulated)
Install software (group-based or individual, simulated)
Collect and log system information

All actions are logged to a logs folder for traceability.

Installation / Setup
Install Python
Make sure Python is installed (recommended Python 3.10 or newer):
https://www.python.org/downloads/
Install required libraries
Run the following command:
pip install psutil

Clone the Repository
git clone https://github.com/yourusername/your-repo-name.git
Then navigate into the project:
cd your-repo-name

How to Run the Program
Run the main file:
python main.py
Example usage
You will get a menu like:

Create User
Install Software
Log System Information
Exit

Select an option and follow the instructions.

Permissions
The script requires:

A Windows environment (tested on Windows 11)
Python installed
Permission to run Python scripts

No administrator access is required since all actions are simulated.

Security
Important notes:

Passwords are stored in plain text in log files
No encryption or secure storage is used
User creation and software installation are simulated (no real system changes are made)
